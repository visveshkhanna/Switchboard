---
title: HTTP API
description: The MCP endpoints the daemon serves.
---

The daemon listens on `http://127.0.0.1:7690` by default and speaks the MCP [Streamable HTTP](https://modelcontextprotocol.io/specification/2025-06-18/basic/transports#streamable-http) transport.

## Endpoints

| Method | Path | Purpose |
|---|---|---|
| `POST` | `/p/:profile/mcp` | send JSON-RPC requests and notifications to the named profile |
| `GET` | `/p/:profile/mcp` | open a server-sent event stream for notifications, such as `tools/list_changed` |
| `DELETE` | `/p/:profile/mcp` | end the session |
| `POST`, `GET`, `DELETE` | `/mcp` | the same, with the profile chosen by header, client rule or default |

On `/mcp`, name the profile with a header:

```http
POST /mcp HTTP/1.1
Host: localhost:7690
Content-Type: application/json
Accept: application/json, text/event-stream
X-Switchboard-Profile: work

{"jsonrpc":"2.0","id":1,"method":"initialize","params":{...}}
```

The reply to `initialize` carries an `Mcp-Session-Id` header. Send it with every later request of the session. The session's profile is fixed at `initialize`; see [Profile resolution](/docs/concepts/profile-resolution).

## Errors

| Situation | Response |
|---|---|
| unknown profile | a JSON-RPC error listing the profiles that exist |
| no profile and no default | a JSON-RPC error explaining how to choose one |
| `Origin` or `Host` not local | `403`, to block DNS rebinding from web pages |
| unknown or ended session | `404`; the client should initialize again |

## Tools

What `tools/list` returns depends on the profile's [surface](/docs/concepts/tool-surfaces):

| Surface | Tools |
|---|---|
| `passthrough` | each allowed tool, named `server__tool` |
| `meta` | `search_tools`, `get_schema`, `call_tool` |
| `code` | `execute`, with `search_tools` and `get_schema` for large profiles |

## stdio

For clients without HTTP support, `switchboard connect --profile <profile>` exposes the same endpoint over stdio. See [stdio bridge](/docs/guides/connect-clients#stdio-bridge).

## Admin API

The web UI is served on the same port and manages servers, profiles and clients through an admin API. Every admin request must carry the token stored in `~/.switchboard/admin-token`. The MCP endpoints do not need it. See [Security](/docs/security).
